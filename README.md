# Weather App

This is a simple weather application that allows users to search for the current weather conditions of a specified location.

## Features

- Search for weather by location
- Display temperature, location, date, and time
- Show weather condition with an icon

## Technologies Used

- HTML
- CSS
- JavaScript
- Weather API

## How to Use

You can use the application in two ways:

1. Access through this link: [https://himanshukhare12.github.io/Weather-App/](https://himanshukhare12.github.io/Weather-App/)
2. Clone the repository and open `index.html` in your browser.

Once you have the application open:

1. Enter the location in the search input field.
2. Click the "Search" button.
3. The weather information for the specified location will be displayed.
